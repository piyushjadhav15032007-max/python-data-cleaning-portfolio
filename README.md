# Python Data Cleaning Portfolio

## Project Overview
This beginner portfolio project demonstrates basic data cleaning and exploratory data analysis using Python and Pandas.

## What I Practiced
- Identifying and removing duplicate rows
- Handling missing values
- Checking potential outliers using the IQR method
- Summarizing data quality
- Creating basic charts

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Important Note
This is a learning demonstration using a small sample dataset. It is not a completed client project.
